 # Simple Calculator with HTML, Tailwind CSS, and Vanilla JavaScript
 
 This repository contains a basic calculator implementation using pure HTML for structure, Tailwind CSS for styling, and
 vanilla JavaScript for functionality. It provides a clean and functional calculator interface.
 
 ## Features
 
  • Basic Arithmetic Operations: Addition, Subtraction, Multiplication, and Division.
  • Clear and Simple Interface: Designed with ease of use in mind.
  • Responsive Layout: Adapts well to different screen sizes.
  • Keyboard Support: You can calculate faster using your keyboard.
 
 ## Technologies Used
 
  • HTML: For structuring the calculator's user interface.
  • Tailwind CSS: For styling the calculator elements with a utility-first approach.
  • Vanilla JavaScript: For handling calculations and user interactions.
